# After School Activities Project - Back-End - CST3144 Full Stack

The back-end server for the After School Activities booking app, built with Node.js, Express.js and MongoDB (native driver).

## List of Progress

1 - Set up Node.js project with Express, MongoDB driver and Cors
2 - Added Logger Middleware (logs each request's method and URL)
3 - Added Static File Middleware (serves lesson images, returns error if not found)
4 - Connected to MongoDB Atlas
5 - Added GET /lessons route returning lesson data from MongoDB
6 - Added POST /orders route for placing an order
7 - Added PUT /lessons/:id route for updating lesson availability
